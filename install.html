ติดตั้งแอป SJ Vault

ทำครั้งเดียวต่อเครื่อง · ได้ไอคอน SJ เปิดเต็มจอ

📱 iPhone / iPad

⬇️ ดาวน์โหลดไอคอนแอป
  1. กดปุ่มด้านบน → กด “อนุญาต” → “ปิด”
  2. เปิดแอป การตั้งค่า → แตะ “ดาวน์โหลดโปรไฟล์แล้ว” (บนสุด)
    ไม่เห็น → ทั่วไป → VPN และการจัดการอุปกรณ์
  3. กด ติดตั้ง → ใส่รหัสเครื่อง → ติดตั้ง → เสร็จสิ้น
  4. กลับหน้าจอโฮม → แตะไอคอน SJ Vault → ใส่ PIN

ขึ้นคำว่า “ไม่ได้ยืนยัน” ได้ตามปกติ (ไฟล์ของร้านเอง ไม่ได้ขอรับรองกับ Apple) · ไฟล์นี้แค่เพิ่มไอคอน ไม่เปลี่ยนการตั้งค่าอื่น · ลบได้ทุกเมื่อ

⚠️ ต้องเปิดด้วย Safari

หน้านี้เปิดจาก LINE / Facebook / Chrome ติดตั้งไม่ได้

  1. กดคัดลอกลิงก์
  2. เปิด Safari → แตะช่องที่อยู่ → วาง → ไป

🤖 Android

✓ ติดตั้งแล้ว — ดูไอคอน SJ Vault ที่หน้าจอ

ถ้าปุ่มไม่ทำงาน ทำเอง:

  1. แตะ ⋮ (มุมขวาบนของ Chrome)
  2. เลือก “ติดตั้งแอป” หรือ “เพิ่มลงในหน้าจอหลัก”
  3. กด ติดตั้ง / เพิ่ม → ไอคอน SJ Vault ขึ้นที่หน้าจอ

⚠️ ต้องเปิดด้วย Chrome

หน้านี้เปิดจาก LINE / Facebook ติดตั้งไม่ได้

เปิดใน Chrome

สแกนด้วยมือถือ

iPhone ใช้กล้อง → เปิดใน Safari · Android ใช้กล้อง/Google Lens → เปิดใน Chrome
